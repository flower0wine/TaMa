# TaMa

TaMa 是一个基于 Android Jetpack Compose 的设备管理应用，提供设备总览、
使用分析、已安装应用信息和常用系统工具入口。

## 主要功能

- 设备状态总览
- 内存、温度、流量与存储分析
- 已安装应用检索与排序
- 系统权限与快捷工具入口
- 本地快照与建议生成

## 技术栈

- Kotlin
- Jetpack Compose
- Navigation Compose
- ViewModel / Lifecycle
- WorkManager
- DataStore

## 说明

项目当前以本地设备数据为主，界面和分析结果用于展示设备状态与辅助操作。
